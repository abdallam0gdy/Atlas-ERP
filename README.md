# 🎓 نظام أطلس لإدارة المراكز التعليمية (Atlas Educational ERP System)

نظام ERP متكامل واحترافي مصمم خصيصاً لإدارة المراكز التعليمية (السناتر)، المدارس، والأكاديميات التدريبية، مع تركيز فائق على إدارة الطلاب، المدرسين، المجموعات، الحضور بالباركود، إدارة الاشتراكات والحصص والمديونيات والتصفية المالية الدقيقة، الخزينة العامة، والصلاحيات الديناميكية، مع نظام صور مضغوط ومحمي ومحلي (Local-First).

---

## 🌟 أبرز مميزات النظام

### 1. 👥 شؤون الطلاب وملفاتهم الموسعة (Students Management)
- تسجيل الطلاب ببيانات شاملة ومفصلة:
  - كود الطالب المميز في السنتر (مثل `#1004`).
  - باركود فريد مطابق لمرحلته الدراسية (مثل `ATL-G01-1004`).
  - **أرقام الاتصال والتواصل العائلي**: رقم موبايل الطالب، رقم هاتف الأب، رقم هاتف الأم، ورقم ولي الأمر المعتمد للطوارئ.
  - **البيانات الشخصية**: النوع (👦 ذكر / 👧 أنثى)، الرقم القومي (14 رقم)، تاريخ الميلاد، والعنوان السكني.
  - **الصورة الشخصية**: رفع فوري مع ضغط ذكي WebP تظهر في الملف والكارنيه وسجل الحضور.
- **توليد وطباعة كروت هوية ذكية واستيكرات QR Code**: جاهزة للطباعة واللصق على الكارنيه لمسح الحضور الفوري.
- صفحة تفصيلية متكاملة لملف الطالب تتضمن كشف الحساب، المجموعات المقيد بها، سجل الحضور، وحركات الدفع.

### 2. 👨‍🏫 هيئة التدريس والمساعدين (Teachers & Assistants)
- إدارة متقدمة وشاملة لملفات المدرسين:
  - الاسم الكامل واسم الشهرة / اللقب (مثل: *مستر أحمد الباشا*).
  - النوع (👨 أستاذ / 👩 أستاذة)، الرقم القومي، تاريخ الميلاد، ورقم الموبايل والبريد.
  - **إسناد المواد**: حصر المدرس في مواده وتخصصه لمنع أخطاء إنشاء المجموعات.
  - **بيانات السكرتارية والمساعدين**: اسم مسؤول السكرتارية ورقم تليفونه مع إمكانية الاتصال المباشر.
  - **نبذة تعريفية وروابط التواصل الاجتماعي**: فيسبوك، يوتيوب، تليجرام، وواتساب.
  - **صورة المدرس الشخصية + شعار المدرس (Logo)**: للطباعة على الملازم وكروت الحضور والتقارير.
  - **مرونة الحسابات المالية على مستوى المجموعات**: تم نقل النسب والمبالغ المالية لتكون مخصصة ومستقلة لكل مجموعة على حدة، حيث يمكن لنفس المدرس أن تختلف نسبته أو قيمة حصته من مجموعة لأخرى بحسب المرحلة أو كثافة القاعة.

### 3. 📦 نظام حزم المواد والباكدجات الشاملة (Package Bundles System)
- **إدارة باكدجات المراحل الدراسية**:
  - إنشاء حزم شاملة لكل مرحلة (مثل: باكدج الصف الرابع الابتدائي) تجمع كافة المواد المقررة.
  - ربط مرشحين متعددين للمجموعات التابعة للباكدج (`package_groups`) عبر شاشة مخصصة لإدارة المجموعات والتسكين.
  - دعم تعدد المجموعات لنفس المادة (مثلاً: 3 مجموعات لمادة اللغة العربية بمواعيد ومدرسين مختلفين).
- **قواعد التسكين الإلزامية والصارمة (Strict 1-Group-Per-Subject Constraint)**:
  - التحقق البرمجي التام (Frontend & Backend) من وجوب اختيار **مجموعة واحدة فقط** لكل مادة مقررة في الباكدج.
  - منع تكرار اختيار أكثر من مجموعة لنفس المادة منعاً باتاً مع إشعار خطأ فوري وواضح.
  - التحقق من اختيار جميع المواد المقررة في الباكدج قبل إتمام القيد.
  - **تسكين الطالب الفوري والمتزامن**: تسجيل الطالب آلياً في جميع المجموعات المختارة بضغطة زر واحدة في جدول قيود المجموعات (`group_enrollments`) وسجل الباكدج (`student_package_enrollments`).
  - سجل تفاعلي لمتابعة الطلاب المشتركين في كل باكدج ومجموعاتهم المختارة وتاريخ التسكين.

### 4. 💳 نظام الاشتراكات والخصم الدائم والتصفية (Subscriptions, Discounts & Refunds)
- **الخصم الدائم والمثبت (Persistent Student Discounts)**:
  - تثبيت خصم الطالب (مبلغ ثابت أو نسبة مئوية) كجزء من قيد الطالب في المجموعة (`group_enrollments`).
  - يظهر الخصم تلقائياً وبشكل دائم في كل عملية تجديد مستقبلية دون الحاجة لإعادة إدخاله يدوياً كل شهر.
- **شحن وتجديد رصيد الحصص**:
  - باقات سريعة (حصة واحدة، حصتين، 3 حصص، شهر 4 حصص، شهر 8 حصص).
  - مرونة الدفع الجزئي وتسجيل المتبقي كمديونية رسمية على حساب الطالب.
  - ربط فوري مع الخزينة العامة بإشعار إيداع رسمي لكل حركة دفع.
- **سداد المديونية المباشر (Pay Debt)**:
  - نافذة مخصصة لسداد مديونية الاشتراكات دون تعديل رصيد الحصص مع منع تجاوز المبلغ المستحق.
- **تصفية الحساب واسترداد الحصص العادلة (Clearance & Refunds)**:
  - احتساب القيمة المستردة للحصص **بالسعر الفعلي المخفض بعد الخصم الدائم للطالب** وليس بالسعر الأصلي لحماية أرباح السنتر.
  - خصم إلزامي وتلقائي لأي مديونية مستحقة قبل صرف أي مبلغ نقدي من الخزينة.
  - إمكانية إسقاط قيد الطالب تلقائياً وتسجيل إذن صرف نقدية من الخزينة.

### 5. ⚡ الحضور والانصراف الذكي (Smart Attendance & Gate)
- مسح كروت الطلاب بكاميرا الهاتف أو أجهزة قراءة الباركود (Barcode Scanner) بسرعة فائقة.
- كشف تلقائي للحصص والمجموعات المجدولة في نفس التوقيت.
- خصم تلقائي لرصيد الحصص المشحونة للطالب عند تسجيل الحضور، مع تنبيه فوري بالصوت والشاشة في حال عدم وجود رصيد كافٍ أو وجود مديونية.

### 6. 📸 نظام إدارة الصور والوسائط المشفر (Secure Local-First Media System)
- **ضغط فوري عبر Sharp**: تحويل جميع الصور المرفوعة تلقائياً إلى صيغة `WebP` فائقة الخفة بجودة مدروسة، وتوفير أكثر من **90% إلى 95%** من حجم الملفات.
- **حماية وتشفير الأسماء**: توليد أسماء عشوائية مشفرة غير قابلة للتخمين إطلاقاً بطول 48 خانة (Cryptographically Secure Hex) لمنع أي محاولة لسحب الصور أو استنتاج روابطها.
- **تنظيم محلي متكامل (Local Storage)**:
  ```
  server/uploads/
  ├── students/     # صور الطلاب الشخصية
  ├── teachers/     # صور المدرسين
  ├── logos/        # شعارات ولوجوهات المدرسين
  └── users/        # صور موظفي ومستخدمي النظام
  ```
- جاهزية الربط السحابي (ImgBB / Cloud Storage) عند إجراء المزامنة مع قاعدة البيانات الأونلاين.

### 7. 🔐 إدارة الحسابات وحماية الصفحات والـ API (RBAC & Route-Level Security)
- **تسجيل الدخول المرن**: إمكانية تسجيل الدخول باسم المستخدم (Username) أو برقم الهاتف (Phone Number).
- **أدوار ديناميكية (Dynamic Roles)**: إنشاء وتعديل أي نوع حساب (مثل: موظف استقبال، مشرف قاعات، مدير فرع).
- **التحكم بالصفحات (Allowed Pages)**: واجهة مرئية بمربعات اختيار (Checkboxes) لتحديد الصفحات المسموحة فقط لكل رتبة.
- **الحماية الصارمة للمسارات والصفحات (Frontend & Backend Route Guards)**:
  - **الواجهة الأمامية**: حماية مسارات المتصفح داخل `<ProtectedRoute pageId="...">` تمنع فتح أي صفحة غير مصرح بها من شريط العنوان وتحول المستخدم فورياً مع رسالة تحذيرية بالرفض.
  - **الخادم الخلفي**: طبقة حماية برمجية `requirePageAccess(pageKey)` على كل مسار في الـ API ترفض الطلبات غير المصرحة بـ `403 Forbidden` حتى وإن تم إرسالها من خارج الواجهة.
- حماية فائقة لحساب المالك الأساسي لمنع حذفه أو تعطيله بطريق الخطأ.

### 8. 💰 الخزينة العامة والحركات المالية (Treasury & Cash Flow)
- تسجيل آلي لكافة حركات الإيرادات (تحصيل اشتراكات، سداد مديونيات، بيع ملازم) والمصروفات (أذونات الصرف، استرداد التصفية).
- مراقبة رصيد الخزينة اللحظي وتقارير دورية للإيرادات والمصروفات وصافي التدفق النقدي.

### 9. 📚 الملازم والمطبوعات والمخزن (Booklets & POS)
- إدارة ملازم ومذكرات المدرسين حسب المرحلة والمادة وسعر البيع وتكلفة الطباعة وتتبع الحجوزات والتسليم.
- نقطة بيع فورية (POS) لبيع الأدوات المدرسية والملازم وربطها بالخزينة.

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend)**:
  - React 19 + Vite 8
  - TailwindCSS + Vanilla CSS (Atlas Modern Design System)
  - TanStack Query (React Query) + Lucide React Icons
  - React Router DOM 7 + React Hot Toast
- **الواجهة الخلفية (Backend)**:
  - Node.js (v18+) + Express.js 5
  - Multer (In-Memory Processing) + Sharp (WebP Compression & Optimization)
  - Crypto (Secure Token Generation)
  - JWT Authentication + Bcrypt + Helmet + CORS + Morgan Logger
- **قاعدة البيانات (Database)**:
  - PostgreSQL 14+ (مُختبر ومعتمد على PostgreSQL 18)
  - Connection Pooling (`pg` pool) مع دعم كامل للـ Transactions و Foreign Keys المتتالية.

## 🚀 طريقة التثبيت والتشغيل السريع

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- PostgreSQL (الإصدار 14 أو أحدث)
- مدير الحزم `npm`

---

### 1. إعداد قاعدة البيانات (Database Setup)

تأكد من إنشاء قاعدة بيانات باسم `atlas_erp_local` على خادم PostgreSQL المحلي:
```bash
createdb -U postgres atlas_erp_local
```

ثم قم بتنفيذ ملف المخطط الرئيسي الموحد الشامل:
```bash
cd server
PGPASSWORD=admin psql -U postgres -d atlas_erp_local -f migrations/000_full_schema.sql
```

لتطبيق التحديثات الأخيرة (الخصم الدائم وحقول الملفات):
```bash
PGPASSWORD=admin psql -U postgres -d atlas_erp_local -f migrations/001_add_profile_fields_and_discounts.sql
```

---

### 2. إعداد ملف البيئة (Environment Variables)

قم بإنشاء ملف `.env` داخل مجلد `server/`:
```env
PORT=5000
NODE_ENV=development
DB_HOST=localhost
DB_PORT=5432
DB_NAME=atlas_erp_local
DB_USER=postgres
DB_PASSWORD=admin
JWT_SECRET=your_super_secret_jwt_key_atlas_erp_2026
JWT_EXPIRES_IN=7d
CORS_ORIGIN=http://localhost:5173
```

---

### 3. تثبيت الاعتماديات وتشغيل السيرفرات

#### تشغيل خادم الباك إند (Backend Server):
```bash
cd server
npm install
npm run dev
```
يعمل الباك إند افتراضياً على: `http://localhost:5000`

#### تشغيل خادم الفرونت إند (Frontend Client):
```bash
cd client
npm install
npm run dev
```
يعمل الموقع افتراضياً على: `http://localhost:5173`

## 🔒 حماية وخصوصية الميديا والبيانات
- جميع الصور يتم معالجتها داخل الذاكرة العشوائية (RAM) عبر `multer.memoryStorage` قبل حفظ النسخة المضغوطة فقط على القرص بصيغة `WebP`.
- جميع أسماء الملفات تستخدم رموز تشفير عشوائية بطول 48 حرفاً تمنع التخمين أو الزحف العشوائي.
- مسار `server/uploads/` مستبعد بالكامل من Git للحفاظ على سرية ملفات المركز التعليمي.
