# 🎓 نظام أطلس لإدارة المراكز التعليمية (Atlas Educational ERP System)

نظام ERP متكامل واحترافي مصمم خصيصاً لإدارة المراكز التعليمية (السناتر)، المدارس، والأكاديميات التدريبية، مع تركيز فائق على إدارة الطلاب، المدرسين، المجموعات، الحضور بالباركود، إدارة الاشتراكات والحصص والمديونيات والتصفية المالية الدقيقة، والخزينة العامة.

---

## 🌟 أبرز مميزات النظام

### 1. 👥 شؤون الطلاب (Students Management)
- تسجيل الطلاب ببيانات شاملة (كود الطالب المميز، الاسم، الهاتف، هاتف ولي الأمر، المرحلة الدراسية، المجموعات).
- توليد وتخصيص وطباعة كروت هوية ذكية للطلاب تحتوي على **QR Code / Barcode** لتسجيل الحضور الفوري.
- صفحة الملف الشخصي للطالب مع متابعة الأداء، المجموعات المقيد بها، وسجل الحضور والمدفوعات.

### 2. 📅 المجموعات الدراسية والمواعيد (Groups & Scheduling)
- تنظيم المجموعات الدراسية بحسب المادة الدراسية، المدرس، المرحلة التعليمية، والقاعة.
- تحديد سعر الحصة الفردية وسعر الاشتراك الشهري لكل مجموعة على حدة.
- تقييد اختيار المواد الدراسية للمدرس بحيث تظهر فقط المواد المسندة إليه، مع تحديد تلقائي في حال كان يُدرس مادة واحدة.
- عرض المجموعات المتوافقة مع المرحلة الدراسية والمادة لتفادي أخطاء الإدخال.

### 3. ⚡ تسجيل الحضور والانصراف الذكي (Smart Attendance)
- مسح كروت الطلاب بكاميرا الهاتف أو أجهزة قراءة الباركود (Barcode Scanner) بسرعة فائقة.
- كشف تلقائي للحصص والمجموعات المجدولة في نفس التوقيت.
- خصم تلقائي لرصيد الحصص المشحونة للطالب عند تسجيل الحضور، مع تنبيه فوري بالصوت والشاشة في حال عدم وجود رصيد كافٍ أو وجود مديونية.

### 4. 💳 نظام الاشتراكات، الحصص والمديونيات (Subscriptions & Debts)
- **شحن وتجديد رصيد الحصص**:
  - باقات سريعة (حصة واحدة، حصتين، 3 حصص، شهر كامل 4 حصص، شهر 8 حصص).
  - إمكانية الدفع الجزئي وتسجيل المتبقي كمديونية تلقائية على حساب الطالب.
  - حساب المديونية السابقة وإلزامية تسويتها مع إمكانية السداد الشامل.
- **سداد المديونية المباشر (Pay Debt)**:
  - نافذة مخصصة لسداد مديونية الاشتراكات دون تعديل رصيد الحصص.
  - حماية منطقية صارمة تمنع إدخال مبالغ أكبر من المديونية المستحقة.
  - توريد المبالغ المحصلة مباشرة إلى الخزينة العامة بإشعار إيداع رسمي.
- **تصفية الحساب واسترداد الحصص (Clearance & Refunds)**:
  - عند رغبة الطالب في الانسحاب أو التصفية، يقوم النظام بحساب القيمة التقديرية للحصص المتبقية.
  - **خصم إلزامي وتلقائي لأي مديونية سابقة** على الطالب قبل احتساب صافي المبلغ المسترد.
  - إمكانية إسقاط قيد الطالب تلقائياً من المجموعة وتسجيل إذن صرف نقدية من الخزينة.

### 5. 💰 الخزينة العامة والحركات المالية (Treasury & Cash Flow)
- تسجيل آلي لكافة حركات الإيرادات (تحصيل اشتراكات، سداد مديونيات، بيع ملازم) والمصروفات (أذونات الصرف، استرداد التصفية).
- مراقبة رصيد الخزينة اللحظي وتقارير دورية للإيرادات والمصروفات وصافي الأرباح.

### 6. 📚 الملازم والمطبوعات الدراسية (Booklets & Study Materials)
- إدارة ملازم ومذكرات المدرسين حسب المرحلة والمادة وسعر البيع وتكلفة الطباعة.
- تتبع مبيعات الملازم للطلاب وتوريد المبالغ للخزينة.

### 7. 🔐 الصلاحيات والأمان (RBAC & Authentication)
- نظام مصادقة آمن باستخدام **JWT (JSON Web Tokens)** و **Bcrypt** لتشفير كلمات المرور.
- أدوار وصلاحيات متعددة (مدير النظام Admin، موظف استقبال Receptionist، كاشير الخزينة Cashier، مدرس Teacher).

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend)**:
  - React 19 + Vite 8
  - TailwindCSS + Vanilla CSS (Atlas Design System)
  - Lucide React Icons
  - React Router DOM
  - Axios + React Hot Toast
- **الواجهة الخلفية (Backend)**:
  - Node.js + Express.js
  - Architecture: Controller-Service-Repository Pattern
  - JWT Authentication + Helmet + CORS + Morgan Logger
- **قاعدة البيانات (Database)**:
  - PostgreSQL
  - Connection Pooling (`pg` pool)

## 🚀 طريقة التثبيت والتشغيل السريع

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- PostgreSQL (الإصدار 14 أو أحدث)
- مدير الحزم `npm`

---

### 1. إعداد قاعدة البيانات (Database Setup)
تأكد من إنشاء قاعدة بيانات باسم `atlas_erp_local` على خادم PostgreSQL المحلي:
```bash
createdb -U postgres atlas_erp_local
```
ثم قم بتنفيذ ملف التهيئة والجداول الأساسية (إن لزم):
```bash
cd server
npm run migrate
```

---

### 2. إعداد ملف البيئة (Environment Variables)
قم بإنشاء ملف `.env` داخل مجلد `server/`:
```env
PORT=5000
NODE_ENV=development
DB_HOST=localhost
DB_PORT=5432
DB_NAME=atlas_erp_local
DB_USER=postgres
DB_PASSWORD=admin
JWT_SECRET=your_super_secret_jwt_key_atlas_erp_2026
JWT_EXPIRES_IN=7d
```

---

### 3. تشغيل السيرفرات (Running Servers)

#### تشغيل خادم الباك إند (Backend Server):
```bash
cd server
npm install
npm run dev
```
يعمل الباك إند افتراضياً على: `http://localhost:5000`

#### تشغيل خادم الفرونت إند (Frontend Client):
```bash
cd client
npm install
npm run dev
```
يعمل الموقع افتراضياً على: `http://localhost:5173`

## 🛡️ قواعد الأمان المالي المطبقة (Financial Business Rules)

1. **حماية المديونيات**: يرفض النظام رفضاً قاطعاً سداد مبالغ تتجاوز المديونية الفعلية للطالب.
2. **التصفية والاسترداد**: تُخصم أي مديونيات متراكمة من إجمالي قيمة الحصص المتبقية تلقائياً قبل تسليم أي نقدية للطالب أو ولي أمره.
3. **تزامن الخزينة**: كل عملية مالية (شحن، سداد مديونية، تصفية، شراء ملازم) تُقيد فوراً بسجل الخزينة بإشعار ومبرر إداري واسم المستخدم القائم بالعملية لضمان الرقابة والشفافية.
